Versión del motor: Unity 6000.3.23 f1

///Clases 7 y 8
Instrucciones para ejecutar: Abrir el proyecto, ir a la escena SampleScene.unity, posteriormente ejecutar con la escena con control + P para Windows o cmd + P para MAC, o dar click a la flecha verde en la parte superior.
Escena utilizada: SampleScene.unity
Controles necesarios: Durante la ejecución ninguno, para ejecutar se puede utilizar teclado o ratón.

Clases 9 y 10
Instrucciones para ejecutar: Abrir el proyecto, ir a la escena PCG_Basic.unity, posteriormente ejecutar con la escena con control + P para Windows o cmd + P para MAC, o dar click a la flecha verde en la parte superior.
Escena utilizada: PCG_Basic.unity
Controles necesarios: Durante la ejecución se puede usar el clic derecho para modificar las rotación de la cámara WASD para moverse y QE para subir y bajar , para ejecutar se puede utilizar teclado o ratón.
